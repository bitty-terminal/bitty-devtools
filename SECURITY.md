# Security Policy

## Supported Versions

No version of Bitty DevTools has been released. The project is
pre-implementation and there is nothing to install or run.

| Version                  | Supported |
| ------------------------ | --------- |
| unreleased (no versions) | No        |

Once an initial release exists, this table will list supported versions and
the support window for each.

## Reporting a Vulnerability

To report a security vulnerability, open a
[GitHub Security Advisory](https://github.com/bitty-terminal/bitty-devtools/security/advisories/new).

Do not report security vulnerabilities via public GitHub issues.

Please include as much of the following as possible:

- the affected component or documented behavior;
- steps to reproduce or a proof of concept;
- the potential impact, including any trust boundary crossed;
- any suggested mitigation, if known.

## Disclosure Policy

- Reports are handled privately by the maintainers through the Security
  Advisory until a fix and coordinated disclosure plan are agreed.
- We ask reporters not to disclose details publicly until a fix is available
  and a disclosure date has been agreed.
- If a report is declined, we will explain why and, where useful, document the
  reasoning so the decision is auditable.
- Credit is given to reporters in release notes unless anonymity is requested.
